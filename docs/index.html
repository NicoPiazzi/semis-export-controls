Chips under control: how semiconductor stocks react to export controls

Since 2019 the US, the Netherlands, Japan and China have used export controls as a weapon in the chip race. This project measures how the stock market prices each announcement, separating the reaction to the news from the movement of the whole market, and asks whether investors punish the whole sector or only the part of the supply chain that each rule targets.

6. Method in brief

Market model. For each stock and announcement I estimate how the stock normally moves with its home market (alpha and beta) on 250 trading days ending 11 days before the news, leaving out the days around other announcements. The abnormal return is the actual return minus the return the model predicts; summing it over a window gives the cumulative abnormal return (CAR).

Day 0 by exchange. Each announcement is timed in its own time zone; day 0 is the first session of each stock's exchange that closes after the news. The main window, the announcement day plus the next, is robust when the exact time is unknown.

Tests. All stocks react on the same day to the same news, so they are not independent observations. Stocks are first averaged within each group for each announcement, then tested across announcements (t-test and Wilcoxon).

Limits. Few events (14-16), several tests, and a model that misbehaves on market-crash days (see April 2025). Results are associations around announcement dates, not proof of causality.

Data: daily prices from Yahoo Finance. Announcements, sources and timing notes: data/events.csv in the repository.
